This document defines the foundation, brand rules, tech guidelines, and working methodology for the **Shuddhi** project workspace. All AI agents and developers working in this workspace MUST strictly adhere to these guidelines for all tasks.

## 1. Project Overview & Foundation

**Brand Name**: Shuddhi  
**Tagline**: "Purity in Every Sip."  
**Brand Origin & Location**: 6/316 Jankipuram Extension, Lucknow, Uttar Pradesh, 226021, India (Mobile/WhatsApp: +91 73553 21473; serving Lucknow and neighboring region: Sitapur, Hardoi, Raebareli, Barabanki, Unnao)  
**Brand Positioning**: Shuddhi combines traditional Indian wisdom, artisanal craft heritage from Lucknow and Central Uttar Pradesh, and sustainable living to create elegant reusable copper drinkware for modern consumers.

### Core Brand Values
- Purity
- Sustainability
- Health-conscious living
- Plastic-free lifestyle
- Traditional Indian wisdom
- Quality craftsmanship
- Durability
- Conscious consumption

### Brand Personality
Premium, trustworthy, natural, elegant, authentic, modern Indian, and environmentally conscious. The website must feel like a premium D2C wellness and lifestyle brand rather than a generic copper bottle store.

### Health & Disclaimer Rules
- **DO NOT** make exaggerated medical claims (e.g., "Cures diseases", "Prevents cancer", "Treats diabetes", "Guaranteed immunity boost", "Detoxifies body", "Guaranteed weight loss").
- **DO** use responsible language: "Traditionally used", "Associated with", "May offer", "Traditionally valued for its antimicrobial properties".
- Must include clear disclaimer: *"Shuddhi products are lifestyle products and are not intended to diagnose, treat or cure any medical condition."*

## 3. Visual & Aesthetic Guidelines

- **Primary Palette**: Copper (`#B87333`, `#D48C46`), Warm Cream (`#FDFBF7`), Earth Brown (`#4A3728`), Deep Forest Green (`#1E3A2B`), Off-White (`#F9F6F0`).
- **Typography**: Editorial serif headings + clean modern sans-serif body text.
- **Avoid**: Excessive gradients, neon colors, bright generic ecommerce templates, cluttered layouts, excessive animations.
- **Whitespace**: Generous whitespace with a premium, natural, Indian, minimal aesthetic.

---

## 4. Tech rules

- Plain HTML, CSS and JavaScript only. No frameworks, no build step, no external UI libraries.
- One shared style.css and one shared script.js.
- Mobile first CSS.
- Semantic HTML5 tags.

## 5. Working rules

- Never create files I did not ask for.
- Explain what you changed after each task.
- Ask me any question you need answered before writing the file.
